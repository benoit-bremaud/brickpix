# Security policy

## Supported versions

brickpix has no release yet. Reports apply to the `main` branch.

## Reporting a vulnerability

Do not open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/benoit-bremaud/brickpix/security/advisories/new).

Please include the affected file or feature, the impact and steps to reproduce. You will get an
acknowledgement within 7 days. Fixes are disclosed once merged to `main`.

The application processes photos entirely in the browser and never uploads them; a report showing
image data leaving the page is treated as critical.
